Review 02 / Search + publishing

Preferred sources help publishers. They also harden our habits.

A useful traffic tool can also make selective exposure feel like neutral search infrastructure.

By Danny Siu
August 21, 2026
5 minute read

No sponsorships
No affiliate links

Article reviewed

TechCrunch: Google gives publishers a new way to fight AI-driven traffic losses ↗

My position

The feature is useful and understandable. It should still be labeled as personalization because it can reinforce the reader’s existing source preferences.

What changed

Google is giving publishers an embeddable “Preferred Sources” button. A reader can use it on a publisher’s own website to ask Google to surface more from that outlet across products such as Search, Discover, and news experiences. Google already allows people to select favorite sources in Search; the new button makes the preference easier to set at the moment a loyal reader is already visiting the publication.

The publisher case is straightforward. AI summaries can answer a query before the user visits the reporting that informed it. Search referral losses especially hurt smaller outlets. A direct way for readers to signal loyalty may return attention—and therefore subscriptions or advertising revenue—to original publishers.

The bias is not a bug hidden at the edges

If I tell Google to prefer a publication, I am not simply improving relevance. I am asking the ranking system to give an outlet I already trust more chances to frame future events for me. That can be convenient and still increase confirmation bias.

This dynamic already exists. Search ranking responds to signals such as relevance, prominence, authoritativeness, and user context, while people repeatedly click outlets they recognize. Preferred Sources makes that loop more explicit and more portable across Google’s surfaces.

A preference can be transparent to the user who set it and invisible in its cumulative effect on what that user never sees.

The risk is not that readers will suddenly consume only one website. Google says preferred outlets get more prominent placement when they have fresh, relevant content; other results still appear. The concern is gradual: familiar sources receive more exposure, which produces more familiarity, which can make their framing feel like the default.

Design choices that would keep the feature honest

  • Label preferred-source placements clearly wherever they appear, including AI-generated answers.
  • Show a simple dashboard of selected outlets and make removing them as easy as adding them.
  • Offer a “broaden this view” control that intentionally introduces credible reporting outside the reader’s usual set.
  • Distinguish original reporting from commentary, aggregation, and repetition.
  • Explain whether a source is shown because of quality signals, a user preference, or both.

A fair conclusion

Publishers need better ways to convert loyal readers into direct, recurring audiences, and the new button is one practical attempt. But Google should not frame preference as though it were objective ranking. Readers deserve to know when they are seeing the web as ranked by the system and when they are seeing a version of it shaped by their own past choices.

My verdict: use Preferred Sources for outlets whose original reporting you value—then deliberately add publications with different editorial perspectives. The feature can support journalism without becoming an automatic agreement machine, but only if the reader treats preference as a starting point rather than proof.
